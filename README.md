# CloudCAD

CloudCAD is a piece of software to run cad in the cloud,
It works by defining objects parametrically in a specialised JSON format, and sending it to the server to be "compiled" into a 3d model.
This pushes the computation from the client to the server, to allow for cad modelling on any device that supports modern web apis.

The entire project + name is still WIP, and subject to change.

Eventually I am aiming to build a frontend that can interactively send data to the backend to be compiled, but for now it just takes in json files.
